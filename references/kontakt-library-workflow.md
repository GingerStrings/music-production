# Kontakt 音色库子技能的共用操作

本页只共享工程接入与证据规则。每个库自己的控制表、版本、奏法和延迟由对应子技能维护；当前任务只读实际使用的库。

## 先确定实际接收对象

以库名、版本、NKI / snapshot、脚本模式和保存状态为单位确认规则。区分宿主轨、Kontakt 实例、槽位、MIDI 通道与音频输出；多槽实例中的一个乐器名不能证明其他槽位或通道已经确认。

从当前工程、用户指定的库位置或已有配置确认安装信息。采样位置暂时不可用时保留工程中保存的乐器身份，待存储设备上线后再核对相关文件。

需要识别 CPR / 组件中的乐器时读 [保存状态的静态识别](kontakt-static.md)。需要复制已保存音色到原生工程时读 [轨道构建](cpr-scaffold.md)。NKI 路径、轨名和显示名称都不能替代完整插件状态；现有工具也没有实现任意 NKI 到 Kontakt 组件状态的转换。

## 通用映射与事件

- 各子技能中的值是所列手册的出厂映射。现有保存状态中的重映射、禁用控制器、已卸载奏法和实际 patch 优先；不把同系列其他库的值移植过来。
- 分开记录音乐音符力度、keyswitch 力度和 CC 值。手册中的力度区间可能从 0 起写；实际 MIDI note-on 使用 1–127，力度 0 会成为 note-off。
- 使用音符 keyswitch 时核实 MIDI 数字键号。未确认分配时，可以采用已确认有效的 CC 命令；不要根据宿主八度标签猜键号。
- 所有库的 keyswitch 时值共同遵循 [控制音的可编辑时值](performance.md#keyswitch-与控制音的可编辑时值)：在不影响当前和后续演奏的范围内适量延长，便于点选、拖动和调整；提前量与按键时值分开处理。按住型、释放切换和组合键按当前库的规则安排，不默认生成几毫秒脉冲。

## 仅 CSS / CSSS / CSW / CSB：命令状态

本节只适用于上述四套库；其他库的规则由各自子技能提供。

- CSS / CSSS / CSW / CSB 手册中的 CC58 同时包含奏法、Legato 开关等命令。按目标功能分别发送，保留明确次序；不要将命令值平滑插值。奏法选择与 Legato 开关分别确认，不能把 Sustain 模式名称当作开关已经开启的证据。
- **状态重建的实现推论**：从中段开始播放时，需要恢复最近的奏法、Legato、overlay、弱音器等相关状态。只追踪“最后一个 CC58 值”可能丢掉先前另一类命令的效果；用事件历史或明确初值重建，并核对宿主的 chase 行为。
- CC1 在长音中可控制动态，在短音选择器中又可能切换短音类型。先确认当前 selector 的分配；采用已保存的重映射 / 禁用设置，或按已核对的 selector 值保持所需类型。keyswitch 力度分区不能自动视为 selector 的 CC 分区。
- CC11 在 CSS / CSSS / CSW / CSB 手册的 Config 图中标作 Volume；曲线能改变多少电平、与宿主自动化如何相乘，仍按当前状态确定。它不能自动替代动态层或奏法选择。

## 时间与演奏

手册给出的毫秒数保留为 documented 的近似值，不能标成音频实测。连奏过渡、起句首音、重起音、短音节奏峰值和释放分别处理。先确定接收音符的真实力度与模式，再使用对应表；不要给整轨所有事件统一施加一个提前量。

按照 [演奏与时间坐标](performance.md) 保留谱面位置及触发位置，变速时按速度图换算，检查现有轨道延迟是否已经补偿。keyswitch 和初始 CC 要在相关触发之前生效，预备拍须容纳提前事件。

各库的颤音、重复音和节拍同步奏法按其参考页实现。依赖宿主速度 / transport 的功能不能仅靠把 MIDI 拍位换成秒保证；渲染器不支持时保留这个实际限制。

## 状态修改、运行与交付

默认只用文件、终端和静态检查；不打开或激活前台界面，不使用 Computer Use。后台插件运行、前台界面和 Computer Use 分别继承会话已有授权；编写子技能不增加运行音源的权限。完整规则见 [主技能](../SKILL.md#前台界面与-computer-use默认禁止)。

修改音色配置时先复用已有正确的保存状态或经过验证的适配器。没有所需载入 / 参数写入实现时，可以完成演奏数据和状态要求，并准确说明工程接入的缺口；不把更改显示名称或任意修改不透明字节当作完成加载。实际需要音频且允许后台运行时，再按 [离线渲染](offline-render.md) 操作。

交付用户要求的工程、MIDI、音频或谱面，说明实际完成的操作与影响使用的限制。按问题检查受影响部分，不增加全量逐事件审计、文件哈希或听感审查状态。
