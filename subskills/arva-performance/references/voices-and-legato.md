# 声部、patch 与连奏

参考 Árva Manual 的 PDF 第 3–4、6–7 页。第 7 页记载独唱 patch 的版本更新，具体可用性请核对工程所用版本。

## 编制与 patch 选择

Arva 分别录制男童和女童，并提供 soprano / alto 的 divisi。男童、女童及高低声部是可独立选择的采样对象；不要由“童声”二字推断所有 NKI 都使用同一组人声。

| 目标 | 手册依据与处理 |
| --- | --- |
| 带音节序列的合奏 | Boys / Girls Mixed、Altos、Sopranos 对应 Syllabuilder 类 patch；确定每个实际实例内容 |
| 指定元音连奏 | 每个 divisi 有 Ah、Mm、Ooh 专用 True Legato patch |
| 起音中带元音变化 | Bonus 的 M-Ah、M-Ooh-Ah 类 patch；按其实际内容安排发音 |
| 独唱 | 手册列男女童、不同声部的独唱内容；元音与 Syllabuilder 配置存在差别，以实际文件为准 |

独立写作的声部需要独立控制时使用各自 patch / 实例与 MIDI 通道。Mixed / 合并 patch 是否按音域、叠层或其他方式分配，要取得当前状态依据。不要靠轨道名断言 divisi、人数或实际发声音域。

本手册未列完整数字音域。音区、移调、可发声键与 keyswitch 区域从当前 patch 的映射或可信状态记录取得；超出已知范围时保留问题，不自动换八度或换声部。正常 note-on 力度和键位编号遵循共用操作。

## 两种连奏的实现范围

**专用 True Legato**：手册将 Ah、Mm、Ooh 列为每个 divisi 的复音真实连奏。选择对应元音的 NKI，保留实际 Legato 设置与声部连接。手册第 4 页界面示例还显示 Overlap、Releases、Reverb 和三个麦克风通道；这些开关分别属于保存状态，不能由一个“Legato”名称推断全部已开启。

**Syllabuilder Agile Legato**：手册说明可在库内各音节间使用复音连奏，并提供智能声部处理；示例为保持和弦同时演奏旋律。实现时明确哪些声音需要保持、哪些声部进入下一音，以及音节是否同时推进。它与专用元音的录制连奏路径分别处理。

手册将上述智能声部控制与 sustain pedal 联系起来，但没有完整列出 pedal 阈值、分配及所有模式的行为。将其记录为已知控制关系，具体 MIDI 数值、按下 / 释放次序与模式从当前配置确认；已有钢琴踏板轨不能直接移用。不要宣称每个重叠音或和弦中的每一音都已形成预期过渡。

多声部写作按音乐需要决定音符重叠、重新起音、同音重复与换气。踏板、复音分配和音节序列共同影响连接；单纯延长所有 MIDI 音符不足以说明连奏实现。需要修复具体断句时只检查相关声部、模式与事件。

## 发音与起音

自然起音是本库采样的一部分。辅音、元音、短音和连奏连接的节奏重心可能不同；手册没有提供统一毫秒提前量。使用音节字段的 attack / offset 时保留其设置依据，结合当前 patch 的实际时序安排预备拍。

保留有意的起首辅音、元音变化与换气；需要更紧的节奏时调整受影响音节或短音。未经运行测量的起音时间标为文档依据或估计，不记录为实测，也不把其他弦乐 / 合唱库的连奏延迟当作本库数值。
