# Syllabuilder 3、控制与保存

参考 Arva Manual，PDF 页 3–7；第 5 页的截图仅提供示例状态，按钮位置、谱面图标及显示键名不构成所有 patch 的 MIDI 映射。

## 音节与序列状态

Syllabuilder Engine 3 将录制音节组织为可编辑序列，支持 CONNECT / MORPH，并可保存与加载 lyric preset。手册列出 10 种合奏音节，截图示例包含 Luh、Pan、Ki、No、Liya、Rih、Leh、Son、Lah、Liyum。独唱可用音节有所不同，按当前 patch 取值。

先明确以下资料，再向工程写音乐音符或切换事件：

| 状态 | 要解决的问题 |
| --- | --- |
| 实际 patch、音节集合与每字段内容 | 确认将发出哪些录制音节 |
| word / 序列槽及当前字段位置 | 明确乐句起点和中途开始播放的状态 |
| CONNECT / MORPH 与连接设置 | 保留用户安排的音节连接或变化 |
| Sustain / Staccato、Agile / 其他模式 | 区分持续音节、短音与连接方式 |
| 推进 / 选择 / 复位的实际触发 | 确定音符、keyswitch、控制器分别承担的功能 |
| 每字段 attack、release、volume、offset | 保存发音时序与音节相对音量 |

CONNECT / MORPH 的具体数值、曲线和触发算法没有在这份简明手册中展开。复用正确的 lyric preset 或完整状态，或通过已验证适配器修改；不要把“已写歌词文本”当作音节引擎已完成配置。

录制音节可用于构造合唱发音与声乐纹理，词句可表达的内容受实际音节集合限制。用户要求清晰、指定语言的歌词时，先核对可表达的音素与连读方式，再说明当前库能实现的范围；不能以 lyric preset 名称宣称任意中文、日文或其他歌词已唱出。

手册说明第 3 代引擎在 Next Generation Choir 系列间交换 lyric preset。交换后仍按目标库确认音节、声部、采样与参数；预置兼容不能证明不同库具有相同音色、动态、音域或时间响应。

## 动态、RR 与控制器

手册合奏概览列：两个录制动态层，加一个用于平滑交叉淡化的 faux 层；Sustain 为 1×RR，Staccato 为 2×RR。faux 层的角色单独记录，避免写成三个独立录制力度层；这些合奏概览也不能自动覆盖全部独唱和 Bonus patch。

区分音符力度、动态层交叉淡化、输出表情与音节选择。当前简明手册没有完整 CC 数值、控制器曲线或 keyswitch 数字键号表。使用当前工程的已保存分配、明确的可读配置或经过验证的映射；没有依据时不自行生成控制命令。特别注意：

- CC1 / CC11 的语义、曲线与是否被宿主自动化覆盖，要在本 patch 确认。
- 踏板控制关系已见手册；实际 MIDI 分配、阈值与模式另行确认。
- 第 5 页截图的 word keyswitch 标签属于示例；确认 MIDI 数字键号后才写事件。
- 重新开始和从乐句中间开始可能需要恢复序列位置及控制状态；取得实际推进 / 复位规则后再实现 chase。

## 麦克风、释放与工程保存

概览列 Close、Decca、Hall 三个麦克风位置以及自定义卷积混响。保存各通道开关、增益、输出及实际 Reverb / Releases 状态；近远景与尾音按本次作品选择。手册截图的数值不作为全库默认混音。

lyric preset 保存的是音节引擎相关资料；完整 Kontakt 状态还涉及实际 NKI、实例槽位 / 通道、麦克风、动态与输出。交付工程时复用完整正确状态或已验证的写入路径，参见 [Kontakt 共用操作](../../../references/kontakt-library-workflow.md)。

常规交付沿用主 skill 的检查范围；仅在具体音节、连接或发声问题出现时针对相应部分验证。
