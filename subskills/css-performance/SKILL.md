# CSS 合奏弦乐

将音乐要求落实到实际 CSS 预置的事件和保存状态。保持用户的配器、表达与版本选择。

先读 [共用操作](../../references/kontakt-library-workflow.md)。写入控制事件或处理时间前，读 [CSS 控制与版本参考](references/controls.md)；该页分别列出 1.5 和 1.7 的演奏规则。

## 进入与实现

1. 确认具体乐器 / Ensemble patch、库版本、当前槽位和控制器重映射。1.5 的 Standard / Advanced 与 1.7 的 Low Latency / Expressive 分开处理；不能只改名称而保留全部旧时间参数。
2. 按乐句选择奏法和 Legato 开关。独立复调声部需要独立接收通道 / 实例；单音连奏模式不能承担任意和弦。
3. 根据当前模式安排音乐音符力度、连接、重复音及 portamento。低力度可能触发滑音，也可能选择慢速过渡；与 keyswitch 自己的力度分开处理。
4. 长音中的 CC1、CC2、CC5 和 CC11 使用参考页中该版本的含义。短音先核实 selector 分配，避免动态曲线意外切换奏法。
5. 延迟按实际奏法 / 模式分别使用；首音和连奏过渡不共用未经确认的数值。CC59 的 RR reset 只在相应版本及需要固定序列时使用。

CSS 与 CSSS 叠加时分别维护模式、事件和时间参数。谱面声部可以共享音乐意图，不能据同系列名称认定两库的振音或连奏相同。

## 状态与交付

已保存的弱音器、麦克风、包络、输出和奏法载入状态属于音色配置。按任务保留或修改，不把厂商偏好的混响 / 模式作为作品的默认选择。

工程接入与后台渲染按共用操作执行。交付所需产物及简明使用限制；文档映射只证明规则有依据，音源加载和实际发声需要相应运行证据。
