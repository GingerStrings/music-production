# NOIRE 钢琴控制与踏板

参考 24 页版 NOIRE Manual。以下均用 PDF 页码，例如 PDF p.11 对应页脚 9。未标注脚本构建，不用文件名推定现有工程版本。

## 演奏与音色

| 设置 | 本库含义及操作边界 | 来源 |
| --- | --- | --- |
| Pure / Felt | 同一台钢琴的普通录音与加装 felt moderator 的录音，分别为独立 NKI | pp.4–5 |
| Velocity Curve | 九种预设，改变力度输入响应；实际力度层和音量还受当前音色设置影响 | p.11 |
| Color | 重新调整采样映射，使声音更软 / 暖或更硬 / 清晰，影响音头 | p.6 |
| Dynamics | 调整音量动态范围，同时仍使用全部力度采样；不等同于持续音的采样层交叉渐变 | p.6 |
| Tonal Shift | 通过采样播放速度改变音色 / 共振特征；与谱面音高、移调和调律分别记录 | p.6 |
| Silent Key | 启用时，很低力度可无正常钢琴音，但仍能产生机械 / 织物声并参与泛音共鸣；手册未列精确阈值 | p.11 |
| Basic Pitch | 可选 436–444 Hz 的基准音高 | p.11 |
| Stretched / Equal | 伸展或平均律调律；手册默认 Stretched | p.11 |

音乐音符使用正力度的 note-on。没有依据时不为 NOIRE 编造固定 CC1、CC2、CC11 或 CC58 参数表；实际 MIDI Learn、宿主参数编号及响应范围从现有状态确认。

## 踏板、离键与持续

延音踏板使用 CC64；该数字映射由 [NI 官方社区关于 NOIRE 的答复](https://community.native-instruments.com/discussion/33091/noire-sustain-release) 补充确认。该版手册主要说明功能本身；遇到其他参数也绑定 CC64 时，先检查接收映射，不把异常归因于钢琴声部。

| 模式 | 已有依据的行为 | 实现注意 |
| --- | --- | --- |
| 延音 | 延音踏板抬起制音器，使按键离开后的弦仍可共鸣 | 保存踏板初值、换踏、释放与重复音；声音仍会自然衰减 |
| Repedal | 启用时，在 note release 期间踩下延音，可延续仍剩余的声音 | 只对尚未结束的释放处理；不能据此宣称恢复已消失的声音 |
| Half Pedal | 启用时，连续踏板影响释放时间及共鸣量；关闭时连续输入按开关使用 | 保留连续控制数据和开关状态，不擅自量化为二值；手册未给出通用响应曲线 |

来源：PDF pp.8、11。手册没有给出半踏各数值对应的物理深度或固定释放毫秒数。先按实际配置明确目标踏板状态，不凭另一个钢琴库的阈值补表。

从中段开始或跨片段渲染时，恢复有效踏板状态与仍在发声的音符 / 共鸣状态；仅补一个 CC64 值不一定复原前面已发声的尾音。换踏、同音重击及结尾的 note-off / 踏板事件保留明确顺序，不在每个分块末尾清零。

## 共鸣、释音与噪声

- Release Samples 是离键时的制音 / 弦停止声音，有独立启用和音量；它与 MIDI 音符时值、踏板和效果尾音分开。来源：p.8。
- Resonance 调整踏板踩下时的弦共鸣；Overtones 调整踏板抬起、多键相互激发的泛音共鸣。Attack 改变音头时间，不能把它当成轨道负延迟。来源：p.8。
- Pedal Noise 有 Rumble、Damper、Strings 分项；机械声有 note-on / note-off 平衡和滤波，Felt Noise 也有独立控制。声音设置与事件实现分别保留。来源：p.9。
- Tonal Depth、Low Keys 与 Sub 层可以额外改变低音和共鸣；Sub 的 split key 决定触发范围。不能仅凭主音符范围判断这些层是否应发声。来源：p.10。
- 该版手册未完整给出可发声键位、所有音区的释放和真实延迟表。需要精确映射时，从当前预置或经授权的受控发声验证取得依据，不以传统钢琴音域或其他库经验代替。

普通钢琴演奏的动态主要落实到击键力度与实际踏板 / 音色状态。电平、音色、音头、共鸣各自处理；只加一条音量曲线不能证明击键层或踏板动作已实现。
