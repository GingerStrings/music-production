# CSW 木管

为当前 CSW 乐器选择并实现具体奏法、吐音、连线和控制数据。先读 [共用操作](../../references/kontakt-library-workflow.md)，写入控制事件前读 [CSW 专用控制参考](references/controls.md)。

## 进入与实现

1. 确认具体木管、独奏 / 双人组、版本、当前奏法载入状态、通道及重映射。库级菜单不证明每个乐器都具有全部奏法。
2. 按句子选择带音头的起句、连接、重吐音和呼吸；改变表情音量不能替代需要的 note-off 与重新起音。
3. 按本库三档力度区分连奏速度，再安排对应近似补偿。保留起句与过渡的区别，不使用 CSS 或 CSB 的延迟。
4. 长音 CC1 动态、CC11 Volume、短音类型选择与 CC2 振音开关分别确认；没有当前预置支持时不写入推测的连续振音曲线。
5. 花舌按长笛类的实际可用性选择。Measured repetitions 的存在、同步及触发方式需在当前 patch 核实，不将 CSB Double Tongue 的参数直接复制过来。

## 状态与交付

按任务使用现有麦克风、包络和输出；CSW 的麦克风配置有自己的结构，不能照搬弦乐 / 铜管的通道数。

工程接入、运行权限和交付遵循共用操作。尚未确认的奏法或参数保持明确边界，不用其他库的同名功能填补。
