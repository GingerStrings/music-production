# Battery 4 鼓组与采样

按用户本次的节奏、编制与音色要求使用 Battery 4。它作为独立采样插件接入工程；读取 Battery 的 kit、cell 和宿主状态。参考 Battery 4 操作手册与 Library Manual。具体插件构建、预置及格式兼容性从当前项目确认。

按需读取：

- 选择鼓组、编写 MIDI、处理力度和踩镲：读 [Cell 映射与演奏](references/cells-and-performance.md)。
- 保存 kit、接入 CPR、处理采样与分输出：读 [状态与路由](references/state-and-routing.md)。
- 克隆轨道或排查“采样可见、无电平”：读 [已知故障与检查工具](references/host-activation.md)，使用附带的只读脚本。

Library Manual 主要解释鼓组风格与颜色分类，参数行为另查对应官方操作章节。

## 实现顺序

1. 延续当前任务的音乐意图。选定具体 kit / cell / sample 后再编写触发。
2. 从当前保存状态或匹配的静态适配器读取实例接收通道、cell 键区、力度层、触发条件、Key Track / Root 和输出。保存实际数值映射；GM 鼓键位、cell 的格子位置或采样文件名均不足以代替映射。
3. 分别处理重音、幽灵音、重复击打与音量。力度既可能改变响度，也可能选择不同采样层；同力度的不同 kit / cell 仍可能相差很大。按鼓件与声部平衡增益，保留用户要求的轻重关系。
4. 根据声音目的选择单次播放、AHDSR 音符释放、循环或互斥组。短 MIDI 音符不会自动截断所有采样；开放踩镲的收束通过当前 kit 的相应配置实现。
5. 新建且应发声的 Cubase 实例须明确设置宿主启用状态，防止从停用的来源轨继承 Active=0；回读新工程的目标实例。保留用户已有轨道的有意停用状态。
6. 按任务交付可编辑工程、音频或 MIDI，并附直接文件链接。用户要求可直接打开的工程时优先提供原生文件，压缩包按需附加。

## 权限与验证范围

继承主 skill 的界面、Computer Use、后台插件执行及文件操作规则。编写子技能和静态检查不启动 Battery、Cubase 或其他宿主；允许后台渲染时使用 [离线渲染](../../references/offline-render.md)。

后台恢复组件并产生声音、CPR 中插件启用、采样路径有效、Cubase 实际播放分别需要相应证据。启用检查脚本只读取保存的宿主标记，不判定声音或宿主兼容性。按出现的问题检查受影响部分，不附加全轨动态审计或试听状态。
